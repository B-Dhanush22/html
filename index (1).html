About the Explorer

This interactive tool loads the complete, curated pharmacogenomic disorder dataset dynamically from your Excel file.

  • SheetJS powers the live Excel reading—no manual data extraction needed.
  • All data columns (currently 21, but unlimited supported) are automatically displayed—inclusive of fields like S.no, literature evidence, and paper links.
  • Search and Filter: Type any keyword to search anywhere in the dataset, across every field.
  • Statistics: Real-time counts for diseases, drugs, genes, RS IDs, and total records—auto-updated with the file.
  • Mobile-friendly, with a beautiful dark interface for less eye strain.
Replace or upload your Excel file any time!
